# Paritosh Tiwari — Personal Portfolio

A modern, minimalist portfolio website for **Paritosh Tiwari**, undergraduate student in **Electronics and Communication Engineering (ECE)** with a specialization in **Semiconductors & Chip Design (VLSI)** at **JECRC University, Jaipur**.

---

## 🌟 Overview & Highlights

- **Aesthetic**: Ultra-clean, modern minimalist theme inspired by high-end design systems (Linear, Vercel). High-contrast dark mode with neutral zinc tones, subtle ambient lighting, and refined typography.
- **Accurate Profile Focus**:
  - **Academic Background**: JECRC University, Jaipur (B.Tech in ECE, specialized in Semiconductors & Chip Design, VLSI).
  - **Skills**: C Programming, English (Fluent), Leadership, German (A2 Level).
  - **Featured Project**: **KrishiSetu** — a platform created to empower smallholder farmers by eliminating middlemen and enabling direct trade with consumers and bulk buyers.
  - **Hobbies & Interests**: Reading books (technology history, literature, biographies), listening to songs and music, and learning the German language.
- **Responsive & Lightweight**: Pure semantic HTML5, clean CSS, and lightweight vanilla JavaScript. No heavy third-party runtime dependencies.

## 🚀 How to View Locally

1. **Direct Browser View**:
   - Double-click `index.html` or right-click and choose **Open with > Google Chrome / Microsoft Edge / Firefox**.
2. **Optional Local Python Server**:
   ```bash
   python -m http.server 8000
   ```
   Open `http://localhost:8000` in your web browser.
